# Fonts

These files are the Latin subsets of three open-source typefaces, each licensed
under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows
bundling them with an app.

| File | Typeface | Copyright |
|---|---|---|
| `russo-one.woff2` | Russo One | © 2011–2012 Jovanny Lemonad (jovanny.ru), with Reserved Font Name "Russo" |
| `oxanium.woff2` | Oxanium (weights 300–800) | © 2019 The Oxanium Project Authors (github.com/sevmeyer/oxanium) |
| `atkinson-next.woff2` | Atkinson Hyperlegible Next (weights 200–800) | © 2020–2024 The Atkinson Hyperlegible Next Project Authors (github.com/googlefonts/atkinson-hyperlegible-next) |

Russo One is used for titles and buttons, and Oxanium for the ship's
instruments (scores, labels). Atkinson Hyperlegible Next is used for every word
a child has to read, including the words on the enemy ships: it was designed so
that letters that are easy to confuse, such as b and d, or I, l and 1, look
clearly different from each other.
