# Fonts

These files are the Latin subsets of two open-source typefaces, each licensed
under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows
bundling them with an app.

| File | Typeface | Copyright |
|---|---|---|
| `caprasimo.woff2` | Caprasimo | © 2023 The Caprasimo Project Authors (github.com/docrepair-fonts/caprasimo-fonts) |
| `atkinson-next.woff2` | Atkinson Hyperlegible Next (weights 200–800) | © 2020–2024 The Atkinson Hyperlegible Next Project Authors (github.com/googlefonts/atkinson-hyperlegible-next) |

Caprasimo is used for titles. Atkinson Hyperlegible Next is used for everything
else, including the letter tiles: it was designed so that letters that are easy
to confuse, such as b and d, or I, l and 1, look clearly different from each
other.
