# Fonts

These files are the Latin subsets of three open-source typefaces, each licensed
under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows
bundling them with an app.

| File | Typeface | Copyright |
|---|---|---|
| `fraunces-soft.woff2` | Fraunces (weight + softness axes) | © 2020 The Fraunces Project Authors (github.com/undercasetype/Fraunces) |
| `literata.woff2`, `literata-italic.woff2` | Literata | © 2017 The Literata Project Authors (github.com/googlefonts/literata) |
| `nunito.woff2` | Nunito | © 2014 The Nunito Project Authors (github.com/googlefonts/nunito) |

Fraunces is used for titles, Literata (a typeface designed for reading books on
screens) for the stories, and Nunito for buttons and labels.
